# Ripcord Community Fix

_(formerly known as `ripcord-audio-hook`)_

A community-made patch to keep Ripcord 0.4.29 alive.

> [!IMPORTANT]
> **Looking for install instructions or downloads?**
> Go to the **[project page](https://geni.site/projects/ripcord-community-fix/)**.

Supports Ripcord 0.4.29 on Windows.  
[Partially supports Ripcord 0.4.29 on Linux.](https://github.com/geniiii/ripcord-audio-hook/tree/linux)

## Building

### If you don't know what you're doing, see the [project page](https://geni.site/projects/ripcord-community-fix/) instead.

1. Install Visual Studio 2019 or newer with the C++ development tools
2. `git submodule update --init --recursive`
3. Run `build.bat`
